# pc-monitor
Szyfrowany, rozproszony system monitorowania i zdalnego zarządzania komputerami.

Encrypted distributed system for monitoring and remote management of computers.

## Zastosowane Technologie / Technologies
Python 3, TCP/IP, TLS, psutil, PySide6, Matplotlib, csv, subprocess

## Instalacja / Installation
    python -m venv .venv
    pip install -r requirements.txt
